# Utopia Kickstarter WordPress theme

A classic WordPress starter theme that reflects the Utopia Kickstarter Figma file. It provides:

- Design tokens in `src/css/global/variables.css`, with fluid type, space and grid scales generated by [Utopia](https://utopia.fyi)
- A library of `u-*` CSS components, layout compositions and utilities
- An icon sprite and JS behaviours
- A PHP component for each design component, which you can use in templates or add to pages through ACF

It comes from the `_wordpress` skeleton in [Chassis](https://github.com/samjoneill/chassis). The frontend source (`src/`) and the Gulp build live at the project root, as in every Chassis project, and build into this theme's `assets/` folder.

## Starting a new site

Run `initproject` and choose `wordpress`. See [docs/new-site.md](docs/new-site.md) for what it does and how to do the same by hand. The theme needs **ACF PRO** and **Classic Editor**.

To put the site on a staging or production server, see [docs/deploying.md](docs/deploying.md).

## Commands

Run from the project root:

```bash
npm install
npm run build   # clean + compile src/ → this theme's assets/
npm run dev     # watch src/
```

`assets/` is build output and is gitignored, so run a build after cloning.

## Structure

Paths are relative to this theme, except `src/`, which is at the project root.

| Path | Purpose |
| --- | --- |
| `src/` (project root) | CSS, JS, images, icons and fonts (the only place to edit frontend assets) |
| `assets/` | Build output, enqueued by `inc/assets.php` |
| `components/*.php` | One file per design component |
| `layouts/` | One file per ACF "Components" layout, mapping its fields onto the matching component |
| `acf-json/` | ACF field groups, kept in version control |
| `docs/` | [Starting a new site](docs/new-site.md), [deploying](docs/deploying.md), [adding a component](docs/adding-a-component.md) |
| `inc/` | Theme setup, asset enqueueing, component helpers, image helpers, ACF integration |
| `header.php` / `footer.php` | Page shell, with empty hook points (`utopia_kickstarter_header`, `utopia_kickstarter_footer`) |
| `front-page.php`, `singular.php`, `index.php`, `404.php` | Page templates |
| `page-templates/components.php` | "Component library" page that renders every component |

## Components

```php
ks_component( 'button', [ 'label' => 'Learn more', 'href' => get_permalink() ] );

// Get the markup as a string instead of echoing it
$html = ks_get_component( 'alert', [ 'text' => 'Saved', 'level' => 'success' ] );
```

Each component file has a docblock with its parameters and an example.

- **Images**: pass an attachment ID (an ACF image array or `WP_Post` also works) plus a registered size name. WordPress builds `srcset` automatically. The sizes are `card` (800w), `content` (1600w), `hero` (2000w) and `avatar` (72×72 crop), and generated sizes are output as WebP. Parameters: `image` / `image_size` / `image_sizes` (hero, article-card), `file` / `size` / `sizes` (image), `avatar` (feature-quote). See `ks_image` and `ks_image_set` in `inc/images.php`.
- **Field group**: takes an `options` array of `[ component, args ]` pairs.
- **Pagination**: `ks_component( 'pagination', ks_pagination_args() )` builds the arguments from the main query.
- **Rich text**: prose `content`, accordion and tab `content` allow HTML (`wp_kses_post`); everything else is escaped.

To see every component, create a page using the **Component library** template.

## Page components (needs ACF PRO)

The block editor isn't used. Pages get a **Components** field (an ACF PRO Flexible Content field) that editors fill in below the main content: Hero, Text Callout, Prose, Feature Quote, Statistic, USP, Accordion, Tabs, Image, Video, Alert, Block Quote, Button.

- The field group is `acf-json/group_ks_components.json`. Field groups load from and save to `acf-json/`, so they stay in version control. Edit them in the ACF UI and the JSON updates.
- `singular.php` and `front-page.php` call `ks_flexible_components()` (in `inc/acf.php`), which renders each row through `layouts/<layout name>.php`. Those files map the row's `get_sub_field()` values onto the matching component.
- To add a component: create the component, add a layout to the field group in the ACF UI, then add `layouts/<layout name>.php`. See [docs/adding-a-component.md](docs/adding-a-component.md) for the full checklist.
- To use it on other post types, add location rules to the field group. Templates other than `singular.php` and `front-page.php` need their own `ks_flexible_components()` call.
- Without ACF PRO the field doesn't exist and nothing extra renders; the rest of the theme works as normal.

## Not included

- **SEO**: use an SEO plugin (e.g. The SEO Framework or Yoast).
- **Favicon/manifest links**: use Settings → General → Site Icon.
